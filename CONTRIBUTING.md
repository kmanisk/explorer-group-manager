# Contributing

Contributions are welcome. Keep changes focused, reversible, and clear about any Explorer or system configuration they affect.

## Workflow

1. Branch from `main`.
2. Follow the setup and usage instructions in `README.md`.
3. Keep each pull request limited to one logical change.
4. Run the relevant formatter, linter, build, and tests available in the repository.
5. Explain the affected behavior and how the change was verified.

For Windows Explorer or registry-related changes, document the keys, paths, or settings touched and include rollback behavior where relevant. Do not commit credentials, machine-specific state, generated build output, or editor-specific files.
